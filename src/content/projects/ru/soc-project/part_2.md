## Windows Server 2022

Windows Server 2022 будет выполнять роль контроллера домена handson.local. Именно на этой машине мы позднее установим Active Directory Domain Services и создадим доменных пользователей. Но сначала нам нужно развернуть саму операционную систему.

Образ можно скачать на сайте Microsoft. Там нам нужно выбрать загрузку в формате ISO.

Когда ISO скачан, открываем VMware и создаём новую виртуальную машину. Задаём имя — мы назовём её DC (Domain Controller) и указываем путь к скачанному ISO-образу. Оперативную память выставляем на 4 GB, процессор - 1 CPU, размер диска - 50 GB. Запускаем машину.

После загрузки установщика нас встретит стандартный экран настроек языка, оставляем всё по умолчанию и нажимаем **Next**, затем **Install Now**.

На экране выбора версии операционной системы нам нужно выбрать **Windows Server 2022 Standard Evaluation (Desktop Experience)**. Если выбрать версию без Desktop Experience, мы получим только командную строку без графического интерфейса.

![windows_installed](/handson/images/soc_project/part_2/installing_win_serv.png)

Как обычно принимаем лицензионное соглашение.

После завершения установки система попросит нас задать пароль для учётной записи **Administrator**. Вводим надёжный пароль и нажимаем Finish.

![windows_installed](/handson/images/soc_project/part_2/pass_winser.png)


Windows Server установлен и готов к работе. Переходим к последней машине.

![windows_installed](/handson/images/soc_project/part_2/winser_installed.png)



## Ubuntu Server

Ubuntu Server будет основой нашей системы мониторинга. На нём мы развернём **Wazuh Manager**, **Wazuh Indexer** и **Wazuh Dashboard**. Именно эта машина будет принимать все события от агентов, анализировать их и отображать алерты. Поэтому мы выделим ей чуть больше ресурсов, чем остальным машинам. Wazuh будет постоянно принимать и индексировать события со всех машин лаборатории, и ей нужен запас производительности.

Для загрузки образа переходим на официальный сайт ubuntu, скачиваем версию Ubuntu Server 22.04 LTS. Версия может незначительно отличаться в зависимости от момента загрузки, но любой релиз в рамках 22.04 подойдёт.

Когда образ скачан, создаём новую виртуальную машину в VMware и называем её **SOC**. Указываем скачанный ISO-образ. Параметры этой машины будут отличаться от остальных: выставляем 8 GB RAM, 2 CPU и 60 GB дискового пространства. Запускаем машину.

После запуска нас встречает меню установщика. Выбираем первый пункт - Try or Install Ubuntu Server. Далее установщик предложит нам выбрать язык, раскладку клавиатуры и настройки сети, оставляем всё по умолчанию и продолжаем нажимать Done или Enter на каждом экране. На экране настройки хранилища установщик предложит конфигурацию по умолчанию, принимаем её и нажимаем Done, затем Continue.

Следующий важный экран, это создание учётной записи. Здесь нам нужно заполнить несколько полей. В поле Your name вводим любое имя. В поле Your server's name вводим **soc** — это будет имя хоста нашего сервера. В поле Username и Password задаём учётные данные, которые обязательно запомним, они понадобятся нам при каждом входе в систему. Нажимаем Done.

![windows_installed](/handson/images/soc_project/part_2/ubuntu_server1.png)

Предложение установить Ubuntu Pro пропускаем. А OpenSSH устанавливаем.

![windows_installed](/handson/images/soc_project/part_2/ubuntu_server2.png)

Когда процесс завершится, в нижней части экрана появится кнопка Reboot Now — нажимаем её. Система может показать ошибку вида **Failed unmounting /cdrom** - это нормальное поведение, просто нажимаем Enter и ждём перезагрузки.

![windows_installed](/handson/images/soc_project/part_2/complete_installation.png)

После перезагрузки нас встречает экран входа в систему. Вводим имя пользователя и пароль, которые мы задали при установке.

![windows_installed](/handson/images/soc_project/part_2/start_ubuntu_server.png)
