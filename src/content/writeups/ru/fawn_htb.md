**Fawn** - это одна из простых машин на платформе HTB, находящаяся в разделе *Starting Point*. В этой задаче мы будем работать с протоколом **FTP**, а также с основными методами для обхода аутентификации и получения флага.

Машина имеет несколько стандартных уязвимостей, таких как открытые порты и неправильные настройки доступа, которые позволяют получить доступ к системе. Основная уязвимость заключается в незащищённом **FTP-сервисе**, который даёт возможность получить доступ к файлам на сервере с помощью простых инструментов.

## Task 1: Что означает аббревиатура FTP?

![02_task1](/handson/images/fawn_htb/02_task1.png)

**FTP** расшифровывается как *File Transfer Protocol* (Протокол передачи файлов). Это стандартный сетевой протокол для передачи файлов между клиентом и сервером через TCP/IP-сеть.

---

## Task 2: На каком порту обычно работает сервис FTP?

![03_task2](/handson/images/fawn_htb/03_task2.png)

По умолчанию, сервис **FTP** слушает на порту **21**. Это стандартный порт для установления соединения с FTP-сервером и передачи файлов между клиентом и сервером.

---

## Task 3: FTP передает данные без шифрования. Какая аббревиатура используется для протокола, который был разработан как безопасная альтернатива FTP и является расширением протокола SSH?

![04_task3](/handson/images/fawn_htb/04_task3.png)

Для безопасной передачи файлов был разработан протокол SFTP (SSH File Transfer Protocol). Этот протокол обеспечивает шифрование данных и защищает их от перехвата, в отличие от FTP, который передает данные в открытом виде.

---

## Task 4: Какая команда используется для отправки ICMP-запроса (ping) для проверки подключения к цели?

![05_task4](/handson/images/fawn_htb/05_task4.png)

Для проверки доступности целевой машины мы используем команду **ping**. Этот инструмент отправляет ICMP echo request на целевой IP-адрес и проверяет, отвечает ли машина. Это один из самых простых способов убедиться, что целевая машина доступна в сети.

---

## Task 5: Какую версию FTP можно определить на целевой машине с помощью сканирования?

![06_task5](/handson/images/fawn_htb/06_task5.png)

![07_nmap_scan](/handson/images/fawn_htb/07_nmap_scan.png)

Во время сканирования с помощью Nmap или подключении через FTP можно определить, что на целевой машине работает *vsftpd 3.0.3*. Это важная информация, так как она помогает понять, какие уязвимости могут быть использованы для эксплуатации. В данном случае, версия *vsftpd 3.0.3* известна уязвимостью для backdoor.

## Task 8: Какой логин используется для входа в FTP, если у вас нет учётной записи?

![12_task8](/handson/images/fawn_htb/12_task8.png)

Если нет учётной записи для входа на FTP-сервер, то можно использовать логин *anonymous*. Этот логин часто используется для доступа к общедоступным FTP-серверам, где не требуется полноценная аутентификация. Суть в том, что FTP-серверы, настроенные для анонимного доступа, позволяют пользователям подключаться без указания пароля или с пустым паролем, что даёт доступ к публичным данным или файлам. Этот логин используется не только на общедоступных FTP-серверах, но и может быть использован для входа в специфические сервисы, настроенные так, чтобы разрешить доступ к определённым файлам без необходимости создания учётной записи.

## Task 9: Какой код ответа мы получаем для сообщения FTP 'Login successful'?

![13_task9](/handson/images/fawn_htb/13_task9.png)

![14_login_suc](/handson/images/fawn_htb/14_login_suc.png)

Когда мы успешно входим на FTP-сервер, сервер возвращает код ответа **230**. Этот код подтверждает успешную аутентификацию и вход в систему.

## Task 10: Существуют несколько команд для вывода списка файлов и каталогов на FTP-сервере. Одна из них — dir. Какая другая команда является стандартной для отображения файлов в Linux-системах?

![15_task10](/handson/images/fawn_htb/15_task10.png)

![16_ls](/handson/images/fawn_htb/16_ls.png)

В дополнение к команде dir, для отображения списка файлов можно использовать команду **ls**. Это стандартная команда для вывода списка файлов в Linux-системах, которая также работает в FTP-сессиях.

---

## Task 11: Какая команда используется для скачивания файла, найденного на FTP-сервере?

![17_task11](/handson/images/fawn_htb/17_task11.png)

![18_get](/handson/images/fawn_htb/18_get.png)

Для скачивания файла с FTP-сервера используется команда *get*. Она позволяет загрузить файл с сервера на локальную машину. Например, чтобы скачать файл flag.txt, нужно выполнить команду: *get flag.txt*
