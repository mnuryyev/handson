# Репозиторий с работами по безопасности и сетевому/системному администрированию

Этот репозиторий содержит различные работы и лабораторные задания по безопасности, сетевому/системному администрированию и инструментам. Все, что представлено в этом репозитории, можно найти на сайте:

👉 [mnuryyev.github.io/handson](https://mnuryyev.github.io/handson)

## Структура репозитория

- 📁 `HTB-THM-CTF/TryHackMe` — Решения задач с платформ **Hack The Box (HTB)**, **TryHackMe (THM)**, **PortSwigger** и других.
- 📁 `network-sysadmin` — Лабораторные работы и проекты по **сетевому и системному администрированию**.
- 📁 `security` — Работы по **информационной безопасности**.
- 📁 `tools` — Инструменты и скрипты для различных задач.
- 📁 `projects` — Проекты.
